## Project Description

This project is a simple rule-based AI agent developed for SLE-1.
The agent takes user input and gives a response according to predefined rules.

## Features

- Responds to greetings
- Provides study suggestions
- Provides coding suggestions
- Suggests taking a break
- Provides sleep-related suggestions
- Displays help for supported inputs

## How to Run

1. Make sure Python is installed.
2. Open the terminal in the project folder.
3. Run:

```text
python student_agent.py
```

4. Enter a message when the agent asks for input.
5. Type `exit` to stop the program.
